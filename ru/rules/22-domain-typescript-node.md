# Предметный пакет: TypeScript и Node.js (`22`)

## Критические правила TypeScript / Node.js
| Область | Ловушка | Обязательная практика |
|---|---|---|
| **Валидация на границах (`🔴`)** | Приведение внешнего JSON, вебхуков, документов БД или `catch (e)` напрямую через `as MyType` или `any` | Считать любые границы ввода-вывода типом `unknown`; сужать тип рантайм-валидаторами (`zod`, `typebox`, явные type guards) и проверять `e instanceof Error` |
| **Гигиена промисов и событий (`🔴`)** | «Висячие» промисы без `await`, передача `async`-коллбэков в `forEach` / `EventEmitter.on` без `.catch`, накопление `.on()` слушателей на каждый запрос/сокет | Всегда `await`-ить или явно `.catch()`-ить каждый промис; снимать подписки через `.off()` / `.once()` / `AbortSignal`, исключая утечки памяти и слушателей |
| **Исходящие таймауты (`🔴`)** | Вызовы `fetch` / `axios` / RPC / `child_process` без дедлайна отмены | Навешивать `AbortSignal.timeout(ms)` или `AbortController` (с обязательным `clearTimeout` в `finally`) на весь внешний I/O |
| **Потоки и память V8** | Буферизация крупных загрузок, архивов или курсоров БД целиком в куче V8 (`Buffer.concat` / `res.arrayBuffer()`) | Передавать крупные объёмы потоково через `pipeline()` из `stream/promises` или ограниченные временные файлы, чтобы `pipeline()` гарантированно закрывал оба конца при ошибке |
| **Безусловная серверная авторизация (`🔴`)** | Отключение проверки токенов, подписей вебхуков, лимитов или изоляции тенантов при `NODE_ENV !== 'production'` | Проверять authn/authz и границы тенанта безусловно в роутах и middleware; в тестах передавать валидные тестовые токены вместо ослабления прод-обработчиков |
| **Безопасность зависимостей и lock-файлов** | Слепое обновление транзитивных пакетов или смешивание `npm` / `yarn` / `pnpm` в одном репозитории | Использовать строго тот пакетный менеджер, чей lock-файл отслеживается в Git (`package-lock.json`, `pnpm-lock.yaml`, `yarn.lock`); проверять `overrides`/`resolutions` при закрытии CVE |
| **Размеченные объединения (Discriminated Unions) и `never`** | Длинные `if/else` по строковым тегам или ненадёжный `instanceof` | Использовать исчерпывающий `switch` с `assertNever(x: never)` вместо длинных `if/else` по строковым тегам или ненадёжного `instanceof` |
| **Конструкторный/фабричный DI и чистый домен** | Мутабельные модульные синглтоны | Инъекция типизированных интерфейсов в чистые доменные сервисы отдельно от HTTP-контроллеров Express/Fastify/Nest/Hono; запрет мутабельных модульных синглтонов |
| **Гигиена графа модулей без barrel-циклов** | Вложенные `index.ts` реэкспорты, вызывающие циклические `undefined`-биндинги | Прямые импорты вместо вложенных `index.ts` реэкспортов, вызывающих циклические `undefined`-биндинги |
