# Предметный пакет: Python (`21`)

## Критические правила разработки на Python
| Область | Ловушка | Обязательная практика |
|---|---|---|
| **Окружение и раннер** | Запуск глобального `python`/`pytest` мимо проектного venv или установка случайных пакетов на лету | Соблюдать тулчейн репозитория (`uv run`, `poetry run` или `.venv/bin/pytest`); сверяться с `pyproject.toml` перед запуском `ruff` / `mypy` / `pytest` |
| **Чистота при импорте (`🔴`)** | Создание движков БД, HTTP-клиентов, сессий `boto3`/облака или чтение отсутствующих env-переменных при импорте модуля | Откладывать инициализацию до явного startup lifespan, фабричных функций или ленивых провайдеров зависимостей |
| **Инварианты безопасности и прода (`🔴`)** | Использование голого `assert user.is_admin` для авторизации, валидации входов или целостности данных | Флаг `python -O` полностью вырезает инструкции `assert`! Бросать явные типизированные исключения (`ValueError`, `PermissionError`, доменные ошибки) либо использовать `icontract` / валидаторы Pydantic |
| **Таймауты Async и ввода-вывода (`🔴`)** | Бесконечные вызовы `httpx` / `aiohttp` / `subprocess` без таймаута или блокирующий синхронный I/O внутри `async def` | Задавать явные таймауты (`httpx.Timeout`, `asyncio.wait_for`), выносить блокирующую работу с CPU/диском в `asyncio.to_thread` и сохранять ссылки на фоновые задачи `asyncio.create_task` |
| **Мутабельные дефолты и замыкания** | `def f(items: list[str] = []):` или позднее связывание переменной цикла в `lambda` | Использовать `None`-сентинел (`items: list[str] | None = None`) или `dataclasses.field(default_factory=list)`; явно связывать переменные цикла |
| **Гигиена исключений** | Голый `except:` или перехват `BaseException` (`CancelledError`, `KeyboardInterrupt`) с проглатыванием | Ловить узкие подклассы `Exception`, сохранять цепочку трейсбека через `raise NewError(...) from err` и никогда не глушить ошибки без структурированного контекста |
| **Типизация и докстринги** | Протекание `Any` через границы модулей или многословные `HOW`-докстринги | Строго типизировать публичные сигнатуры; документировать **ЧТО (WHAT)** (контракт, единицы, исключения) и **ПОЧЕМУ (WHY)** (ограничения) |
| **`Protocol` и композиция вместо глубокого наследования** | Глубокие `ABC`-иерархии и модульные синглтоны | Использовать `typing.Protocol` + конструкторный DI вместо глубоких `ABC`-иерархий и модульных синглтонов |
| **Иммутабельные DTO и Value Objects** | Скрытая мутация входных аргументов | Использовать `@dataclass(frozen=True, slots=True)` или Pydantic v2 `ConfigDict(frozen=True, extra="forbid")` на границах; запрет скрытой мутации входных аргументов |
| **Связность пакетов и жизненный цикл ресурсов** | Циклические импорты | Модули `<=400-600` LOC по доменам без циклических импортов через чистое слоение / `TYPE_CHECKING`; `@contextmanager` / `AsyncExitStack` |
